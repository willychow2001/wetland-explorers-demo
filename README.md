## Presentation notes

Use the student view for the wetland map, activities, companion care, shop and achievements. Switch to the teacher workspace to edit questions, upload artwork, and review responses.

This is a presentation demo with fictional student data. Progress and uploaded artwork stay in the visitor's browser. HKUST sign-in and institutional gradebook transfer are not connected.
